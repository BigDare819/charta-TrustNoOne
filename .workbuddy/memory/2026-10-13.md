# 2026-10-13 阿瓦隆 七项修改

用户要求的一批改动，全部实现并 `gradlew build --offline` 通过（jar: build/libs/myavalon-fabric-1.21.1-1.0.0.jar）。

1. 名牌黄色高亮描边：`AvalonScreen.renderZones` 里 VOTE/QUEST 阶段给"队伍成员"的琥珀色脉冲填充+双层描边
   （0xFFFFE97F）整段删掉，所有座位统一只画一层中性白框。队伍信息保留在名牌顶部的座位色细线（待定/目标时）。
2. 队伍旗偏亮：根因是 `blitFlag` 把 TEAM_FLAG **自身**当成 glow 纹理传给 `blitChartaCard`，等于把模糊后的自己
   用加法混合再叠一遍（整屏 glow buffer 相加），所以比原图亮、且旗子一动就把这层"洗白"拖过名牌和状态文字
   （也就是用户说的"文字闪现"）。新增 `AvalonScreen.blitCardTrueColor`：同一套透视缩放的 quad + hover 倾斜，
   走 `card_argb` 着色器、**不排 glow**。旗帜贴图与素材 md5 一致（不是 PNG 被改过）。
   注意：Charta 的 `charta:card` 是按红色通道查 64 色调色板（调色板格式用于卡面），本项目 `IrisCompatPresent`
   已把 `IrisCompat.isPresent()` 强制为 true 走直采路径；自己画的 PNG 一定不要走 palette 那条路。
3. 队长标志静止：`renderCrown` 去掉两路 sin 浮动，仍保留换队长时的一次弧线飞行。
4. a) 牌堆闪现旗子：`AvalonScreen` 加 `localPending` 乐观掩码（`pendingMask()`/`toggleFlag()`），点击立即本地生效，
   等服务端镜像追上或离开 PROPOSE 阶段即释放，所有读队伍掩码的地方改走它。b) 文字闪现：同上第 2 项（glow 洗屏）。
5. 选队阶段灰滤镜：`isBusy()` 去掉 PROPOSE（ASSASSIN/OVER 仍保留）。
6. 派西维尔/莫甘娜暂不出场：`AvalonRole.compose` 用 LOYALIST + MINION 顶替两个位置，人数/好坏比例完全不变；
   枚举与 AvalonBots/knownMask 里的分支留着（休眠），恢复只需换回两行。
7. 投票改为同时投：`AvalonGame.beginVoting/castVote/tickVoters` 替代原来的 queue 轮询。所有座位一次性 `afterPlay`
   注册；`canPlay` 在 VOTE 阶段不再要求 `player == currentPlayer`（只要求该座位未投票且是投票牌）；
   `PileSlot.canInsertCard` 覆盖掉 Charta 的 `player == currentPlayer` 硬门槛，交给 `canPlay` 判定。
   bot 由 `tickVoters` 用 `voterDelay`（6+rand(18) tick）驱动（AutoPlayer.tick 只在 currentPlayer 上触发，同时投票没有
   "当前玩家"）。UI 侧新增 `AvalonMenu.isLocalPending()`（VOTE 阶段看自己是否已投），`renderPile`/`renderStatus` 改用它；
   新增语言键 `status.myavalon.vote_in`。选任务(beginQuest)保持轮流。
